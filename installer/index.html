CLumo インストーラ

ブラウザから ESP32-C3 へファームウェアを書き込みます。ツールのインストールは不要です。

STEP 1 / 2 — ファームウェアを選ぶ

単独版アプリ不要

ボタン2つだけで完結する clumo-standalone。 デジタルペット・ポモドーロタイマー・サイコロの3モードを搭載します。 Bluetooth もスマホも使いません。

単独版を書き込む →

アプリ協調版Android アプリ連携

Android アプリ「CLumo」と BLE で連携する clumo-companion。 アプリからのタイマー設定・8x8 パターンエディタ「マイ表示」・オーディオビジュアライザが使えます。 アプリは 最新 Release の clumo.apk をどうぞ。

どちらを選んでも、あとからこのページで何度でも書き換えて切り替えられます。 迷ったらまずは単独版がおすすめです。
STEP 2 / 2 — 書き込み方式を選ぶ

PC専用（公式版）推奨

本家 ESP Web Tools（Web Serial）。実績のある公式ツールで書き込みます。 対応は PC の Chrome / Edge / Opera（デスクトップ）のみ。スマホは使えません。

この方法で進む →

PC + スマホ版WebUSB

上記に加えて Android の Chrome（USB-OTG）でも書き込めます。 コミュニティ製フォーク（tasmota-esp-web-tools）を使用します。

この方法で進む →
書き込まれるファームウェアはどちらの方式でも同一です。迷ったら「PC専用（公式版）」を、 スマホから書き込みたいときは「PC + スマホ版」を選んでください。

単独版（clumo-standalone）アプリ協調版（clumo-companion）を PC専用（公式）版PC + スマホ（WebUSB）版で書き込みます。 別の選択にする

このブラウザは未対応です。PC は Chrome / Edge / Opera、スマホは Android の Chromeをご利用ください（iOS・Safari・Firefox は非対応）。 HTTPS 接続でのみ利用できます。

手順

  1. CLumo を USB ケーブルで接続
    • PC：Chrome / Edge にそのまま接続
    • Android スマホ：USB-OTG ケーブルで接続し Chrome でこのページを開く
  2. 上の「インストール」を押す
  3. 表示されたシリアルポート / USB デバイスを選択
  4. 書き込み完了を待つ（自動で再起動します）

書き込み後の使い方

  1. 「インストール完了」後に表示される空のダイアログは閉じて OK です （仕様です。デバイスはすでに起動しています）
  2. LED が点灯し、最初のモードが表示されます
  3. 白ボタンを長押しするとモードが切り替わります （ペット → ポモドーロ → サイコロ → …）
  4. 赤 / 白の短押しが各モードでの操作です （ペットへの餌やり、タイマーの開始 / 停止、サイコロを振る など）
  1. 「インストール完了」後に表示される空のダイアログは閉じて OK です （仕様です。デバイスはすでに起動しています）
  2. LED が点灯し、デバイスが起動します
  3. Android アプリ「CLumo」をインストール （最新 Release の clumo.apk）
  4. アプリを開いてデバイスをスキャンし、CLumo-XXXX に接続。 ペアリングのパスキーは 123456
  5. タイマー・マイ表示（8x8 パターンエディタ）・オーディオビジュアライザをアプリから操作できます

デバイス情報

  • MCUESP32-C3
  • LED8x8 マトリクス (MAX7219)
  • ボタン2つ（赤 / 白）
  • Bluetooth不使用（アプリ不要）
  • BLE デバイス名CLumo-XXXX（末尾は個体ごとに異なる）
  • BLE パスキー123456
対応環境： デスクトップの Chrome / Edge / Opera（Web Serial）で書き込めます。さらに Android の Chrome（USB-OTG / WebUSB）にも対応。 iOS（iPhone / iPad）と Safari・Firefox は非対応です。
Android では充電専用ではなくデータ通信対応の OTG ケーブルを使用してください。
