# Stand Android UI Implementation Plan

**Goal:** 一覧・詳細をスタンド専用の形状と構成にする。ユーザーが本体の絵だけでなく画面構成の変更も選択。
**Architecture:** DeviceKindで描画を分岐。専用Composableにスタンドの図と案内をまとめ、既存の接続・配信・保存処理を再利用。
**Tech Stack:** Kotlin / Jetpack Compose。

- [ ] スタンド本体描画を追加し、一覧・詳細・外観プレビューに適用。既存の筐体・ボタン色を再利用し、未取得のLED状態を捏造しない。
- [ ] 詳細を接続・ビジュアライザ・待機表示・Wi-Fi編集案内に整理。設定案内は接続前でも表示。日英対応。
- [ ] Androidの既存テスト、ビルド、ktlint、実機画面を確認。保存作品を書き換えず掲載用画像を撮影。

音量値表示や新規通信機能、Wi-Fiモードの遠隔切り替えは追加しない。ブラウザ編集は本体操作で移る手順を案内。Androidの既存Animation選択は横スクロールであり、ブラウザの8コマ再生とは区別して表記する。
