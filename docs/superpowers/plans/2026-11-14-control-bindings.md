# 操作割り当て

承認済み: Androidは部位を選ぶネイティブUIと即時保存、Webは一覧・一括保存。本体に共通保存。初期値へ戻すボタンを双方に設置。

1. 版番号付き7バイト（版1、左、右、ノブ1/2/3、回転ペア）を検証しNVSへ独立保存。固定のシステム長押しは対象外。
2. BLE特性0009とHTTP GET/POST /api/bindingsを追加。保存失敗時は旧値維持。
3. Androidは読み戻し確認後に表示更新。Webは明示保存と未保存警告。リセットも同じ保存処理。
4. 初期値: 前へ・次へ・再生/一時停止・次へ・前へ・音量。
5. 不正値・互換・復元テスト、両側ビルド、更新、実機読込保存を確認。既存表示設定を保持する。
