# スタンドの設定モード切り替え（実機試作）

前曲＋次曲を3秒長押しして通常／設定モードを切り替える。ノブ3秒長押しのペアリング操作は維持する。自動復帰とブラウザの「保存して終了」はユーザー指定により設けない。

候補は前曲＋次曲、ノブ8秒、ノブ＋前曲。既存ペアリングと競合しない前曲＋次曲を採用。単独操作を150ms保留して同時押しでは曲操作を抑止する。両押し中は進捗、設定中はWi-Fiマークを表示する。起動時の押しっぱなしでは発動せず、一度全ボタンを離してから受け付ける。

今回は操作と無線切り替えの実機試作。設定モードはSoftAPと接続確認ページまでとし、描画編集は含めない。BLEとWi-Fiを確実に分離するためモード変更時に再起動する。NVSの次回起動フラグは読み取り時に消費し、電源再投入では通常モードに戻る。ペアリング・表示設定は保持する。これは時間による自動復帰とは別の起動仕様。

## キャプティブポータル追加（ユーザー承認済み）
設定APのDHCPで本体をDNSとして配布し、DNSのIPv4問い合わせを本体192.168.71.1へ返す。HTTPのルートは確認ページ、その他のGETはルートへ302リダイレクトする。Android/iOS/macOSのHTTP接続確認を捕捉して設定画面へ案内する。HTTPSの偽装はしない。自動表示されない端末向けに http://clumo.setup/ と固定IPの手動入口も残す。編集機能・終了方法は変更しない。
