手順

Steps

  1. CLumo を USB ケーブルでつなぐ
    • PC: そのままつなぐ
    • Android: USB-OTG ケーブルでつなぎ、Chrome でこのページを開く
  2. 上の「インストール」を押す
  3. 表示されたシリアルポート / USB デバイスを選ぶ
  4. 書き込みが終わるのを待つ。自動で再起動します
  5. 「Select Port」のダイアログが出たら、書き込みは終わっています。同じ CLumo を選び直すと完了画面になります。閉じても構いません
  1. Connect CLumo over USB
    • PC: plug it straight in
    • Android: use a USB-OTG cable and open this page in Chrome
  2. Press "Install" above
  3. Pick the serial port or USB device it offers
  4. Wait for flashing to finish. The device restarts on its own
  5. If a "Select Port" dialog appears, flashing is already done. Pick the same CLumo again to reach the completion screen, or just close it

書き込んだあと

After flashing

  1. 「インストール完了」のあとに空のダイアログが出たら閉じて構いません。本体はもう動いています
  2. マトリクスが点灯し、最初のモードが表示されます
  3. 白ボタンを 1 秒長押しでモードが切り替わります。ペット → ポモドーロ → サイコロの順です
  4. 各モードでの橙 / 白の操作は 単独版の README にまとめてあります
  1. If an empty dialog appears after "Installation complete", just close it. The device is already running
  2. The matrix lights up with the first mode
  3. Hold the white button for a second to switch modes: pet, pomodoro, dice
  4. What orange and white do in each mode is in the standalone README
  1. 「インストール完了」のあとに空のダイアログが出たら閉じて構いません。本体はもう動いています
  2. マトリクスに接続待ちのアイコンが出て、最初のペアリングまでそのまま待ちます
  3. Android アプリ「CLumo」をインストールします。最新の Release の clumo.apk です
  4. アプリを開いて「CLumo を探す」を押し、見つかった CLumo に接続します。パスキーは 123456
  5. ポモドーロ、タイマー、マイ表示、ビジュアライザをアプリから使えます。本体の表示の意味は 協調版の README にまとめてあります
  1. If an empty dialog appears after "Installation complete", just close it. The device is already running
  2. The matrix shows the waiting-for-connection icon and stays on it until the first pairing
  3. Install the CLumo Android app: clumo.apk from the latest release
  4. Open the app, tap "Find CLumo", and connect to the one it finds. The passkey is 123456
  5. Pomodoro, timer, your own pictures, and the visualizer are then all in the app. What the device shows is explained in the companion README
