# Shared stand display editor

**Goal:** 静止画・最大8コマのアニメーションをAndroid/Bluetoothとブラウザ/Wi-Fiの双方で読み込み・編集・保存する。
**Design:** 既存editor.htmlを唯一の編集UIとしてAndroid APKにも同梱。Android WebViewでは限定したローカルbridge経由でGATTの78バイト設定を読み書き。ネットワークのブラウザは既存HTTP APIを使用。端末に保存済みの値を読み戻して完了確認し、プレビューは編集画面内のみ。

- [x] Settings 78バイトのGATT特性を追加（旧単項目によるアニメーション喪失をUIから除去）。MTUを確保。バージョンは3に更新し両側同時更新。
- [x] Androidの設定検証・読込・保存の通信境界をテストして実装。読み戻しは最新の応答で確認。
- [x] HTML共有とAndroid内エディターを追加。外部ナビゲーションと不要なWebViewアクセスを拒否。
- [x] スタンドUIは共通エディター入口とWi-Fi手順に更新。静止画とアニメーションでアプリ／ブラウザの機能差を作らない。
- [ ] ビルド・単体テスト・実機の双方向読込保存を検証し、元データを復元。資料の機能差分を更新。

既存の公開資料取り込み・UI形状変更は保持。公開・push・コミットは指示待ち。

検証状況: Android 294件・Rust 44件成功、両側ビルド成功。ESP32・Android更新済み。実機sharedDisplayRoundTrip成功、元設定復元済み。ブラウザとの往復編集・公開用スクリーンショットは未実施。
