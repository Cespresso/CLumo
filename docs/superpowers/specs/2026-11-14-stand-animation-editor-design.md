# 待機アニメーション編集

ユーザー承認範囲: キャプティブポータルにプリセット選択と最大8コマの8×8編集を追加し、実機へ書き込む。再生速度・明るさ、ブラウザ内プレビュー、明示的な本体保存。保存はモードを終了しない。終了は既存の両ボタン長押し。

ブラウザだけで完結する単一HTMLと本体HTTP APIを使用する。アプリ追加案ではなく既存ポータル拡張を採用。静止画は1コマ、アニメーションは2〜8コマ、周期は100〜2000ms/コマ。プリセットは音符・鼓動・波・CLumoロゴ。追加・複製・削除・順序変更を提供する。

旧10バイト設定を読み取り可能にし、新設定はバージョン付き拡張を同じNVSキーに一括保存する。既存GATT形式は変えず、先頭フレームを代表の絵として扱う。Androidの絵／待機モード書き込みはコマ再生を解除、明るさ変更は保持する。

設定モード中は本体のWi-Fiマークを維持する。プレビューはブラウザ内だけで行う。保存は表示・明るさを変更せず、通常モード復帰時に適用する。実機プレビューAPIは廃止。HTTP APIの入力長・値を検証し、不正入力は保存せず400、NVS失敗は500。既存のペアリング・操作アニメーション・表示向きは維持する。
